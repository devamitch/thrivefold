`Camera → Frame processing → Pose inference → Timestamped result → Coordinate transformation → Landmark state → Exercise engine → Guidance/audio → Skia overlay → Canonical session → History`

Investigate:

- Too many bridge calls.
- Stale inference results.
- Incorrect rotation, mirroring or aspect-fill transformation.
- Repeated detector initialization.

- Excessive smoothing and lag.
- Per-frame logging, database writes or analytics.
- Competing camera, video and audio work.
- Model resource leaks.
- Lifecycle and background/resume errors.

Fix root causes. Do not add new libraries or rebuild the camera pipeline without evidence that the existing architecture cannot meet requirements.

## 9.2 Deliver a cohesive exercise journey

Make the complete journey work:

`Exercise selection → Instructions → Camera setup → Tracking readiness → Countdown → Live session → Feedback → Reps/hold/sequence → Rest/set transition → Completion summary → Persisted history`

All transitions must be driven by actual session state.

### Exercise introduction

Provide the required instructions, purpose, expected reps/duration, equipment, camera angle, useful modifications, important cautions and actual verification capability.

### Camera setup

Guide the user into the correct frame using genuine detection/readiness conditions.

Handle framing, full-body visibility, relevant joints, lighting and camera angle. Do not declare readiness simply because the camera opened.

Offer an appropriate timer/manual fallback when camera verification is not available.

### Active session

Keep the camera as the dominant surface.

Display the relevant exercise, set, valid rep count or hold duration, short actionable cues, and working pause/resume/stop and optional sound controls.

Preserve session state through layout changes and interruptions.

Implement fullscreen/system-bar behavior safely. Restore system UI on exit, navigation, app backgrounding and errors. Android back must always remain usable.

- Correct anatomical connections.
- Smooth, consistent strokes.
- Carefully emphasized relevant joints.
- Subtle confidence/tracking states.
- Useful movement guides and reference angles where justified.
- No unnecessary visual clutter.
