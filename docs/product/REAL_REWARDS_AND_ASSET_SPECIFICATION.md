## 1. Executive Summary: The Hard-Earned Value Philosophy

In Thrivefold, **gems are scarce, valuable, and never given away easily**. 
Meaningful health habits require genuine personal commitment. To reflect this, our economic hierarchy operates on a rigorous 4-step progressive pipeline:

```
[Daily Verified Habits] ──► [XP & Leveling] ──► [Scarce Gems] ──► [Sanctuary Tickets] ──► [Marketplace Tokens] ──► [Real Merch & Services]
```

### The 4 Pillars of the Real Deal:
1. **Gems Are Hard to Earn**: No inflation. Gems require strict habit consistency, streaks, and proof (camera vision, step sensor, active breathing time).
2. **The 3-Day, 7-Day & 30-Day Retention Multipliers**: Habit adherence multipliers dramatically scale rewards for users who commit over time.
3. **The Ticket-to-Token Conversion Gate**: Tickets are forged from scarce gems. Once enough tickets are accumulated, they convert into **Marketplace Tokens** — the exclusive currency that unlocks the Open Marketplace.
4. **Transparent Token Pricing Catalog**: Every single item — from handcrafted beechwood pushup bars to precision gyroballs, children's cricket kits, certified clinician telehealth visits, and nutritious home meals — has an explicit, unyielding Token Price tag.

## 5. Physical Dispatch & Delivery Guarantee

When a user reaches the required **Token Price** and initiates redemption:
1. **Marketplace Order Modal**: An on-device modal gathers:
   - Full Name
   - Complete Shipping Address, Street, Apartment / House Number
   - City, State / Province, Postal / PIN Code
   - Recipient Contact Number (for courier SMS updates)
2. **Token Burning**: The exact Token cost is subtracted from `rewardsSlice.marketplaceTokens`. A tamper-proof cryptographic order hash is recorded: `TF-TOKEN-MKT-<TIMESTAMP>-<RANDOM_SALT>`.
3. **Owner Fulfillment & Dispatch Guarantee**:
   - Every physical item is personally inspected, packaged with custom Thrivefold unboxing tissue, an exclusive Die-Cut Vinyl Sticker Sheet, and an authenticated Certificate of Habit Achievement.
   - Courier tracking code is pushed directly to the user's **Orders & Shipments** screen.

## 7. Store Implementation & Data Structures

### Store Slice (`src/stores/slices/rewardsSlice.ts`)

```typescript
export interface ShippingDetails {
  fullName: string;
  addressLine1: string;
  addressLine2?: string;
  city: string;
  state: string;
  postalCode: string;
  phone: string;
}

export interface MarketplaceOrder {
  orderId: string;
  itemKey: string;
  itemTitle: string;
  tokensCost: number;
  orderTimestamp: number;
  status: 'ordered' | 'inspected' | 'dispatched' | 'delivered';
  trackingNumber?: string;
  shipping: ShippingDetails;
}

export interface RewardsSlice {
  // Streak & Multipliers
  currentStreakDays: number;
  streakMultiplier: number;
  
  // Currencies
  amberGems: number;
  sanctuaryTickets: number;
  marketplaceTokens: number;
  goldenGems: number;
  
  // Progression & Market
  isMarketplaceUnlocked: boolean;
  unlockedStickers: string[];
  activeStatusTitle: string;
  marketplaceOrders: MarketplaceOrder[];
  
  // Actions
  recordHabitAction: (habit: 'brief' | 'water' | 'workout' | 'meds' | 'meal' | 'journal' | 'voice' | 'share') => void;
  forgeTicketsFromGems: (amountTickets: number) => boolean;
  forgeTokensFromTickets: (amountTokens: number) => boolean;
  redeemMarketplaceItem: (itemKey: string, itemTitle: string, tokenCost: number, shipping: ShippingDetails) => string;
}
```
