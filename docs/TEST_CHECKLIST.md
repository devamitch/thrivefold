# Thrivefold — test checklist (owner device)

Build installed on the Moto G71. Beta screens need **Beta Mode on**: Settings → Developer tools (or Beta Lab) → Activate Beta. Owner rows appear after Google sign-in with the owner account.

## Account
- [ ] Sign in with Google → birthday and gender come from Google (People API now enabled) → no form → Home. If the form appears, enter the birthday once.
- [ ] Sign out, sign in again (or on another phone) → no birthday form; space and goals restored.
- [ ] Settings → **Your profile**: languages, food rules, allergies, interests, accessibility, emergency contacts → Save to my account.
- [ ] Home → one profile question a day (height, weight, eating style…); "Not now" hides it for a week.

## Home and outdoors
- [ ] Outdoors card → search your town → weather now, best walk hour, tips, official NDMA alerts (if any), Emergency 112.
- [ ] Outdoors → **Plan an outing** → "Durga Puja pandal" → pick places → walking order and times. *(Needs Routes API + Places API (New) allowed on the Maps key; until then it shows the exact reason.)*
- [ ] Outdoors → **Trip check-in** → destination + time → notification at arrival time → "I've arrived" / Share my location (opens SMS) / Ask for help.
- [ ] Steps tile → sheet; Calories; Hydration; Beta card shows today's practice.

## Health
- [ ] Health → Medications → add one → "Remind me at these times" → reminder at that minute.
- [ ] Medications → Doctor follow-ups → add a date → reminders the evening before and the morning of.
- [ ] "Order medicines online" opens Google Play pharmacy search.

## Beta Lab (Settings → Beta Lab)
- [ ] Eye Tracking Studio: live distance/blinks; Blink Bloom; near/far; focus game; coach speaks alerts.
- [ ] Eye Pursuit: follow the dot 30 s → score saved.
- [ ] Face & eye exercises: calibrate, six movements counted with the coach.
- [ ] Hand Games: Finger count and Gesture match (thumbs up, peace, palm, fist, point up).
- [ ] Hand gestures: grip reps.
- [ ] Pose coach.
- [ ] Breathing coach: 1 min+ completes today's guided-exercise quest (if assigned).
- [ ] Voice practice: hold "aah", steady loudness, say it clearly (microphone).
- [ ] Body & Style: selfie → face shape, frames, PD; full-length → posture score, outfit colours, fit tips; BMI and meal plan.
- [ ] Thrive Coach: type or tap the mic — "how many steps today", "log two glasses of water", "will it rain", "plan an outing", "start breathing".
- [ ] Progress tab → Beta → guided-practice chart.

Report anything that fails with the screen name; logs are read over USB.
